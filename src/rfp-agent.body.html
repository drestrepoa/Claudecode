Building blocks — edit me

Four things participants change. Edit, then ask the agent again and watch the trace.

1 · The brief

agent

Standing instructions the agent reads every time. Who it works for, what good looks like, what it must never do. Try deleting the last paragraph and sending the RFP-17 prompt.

2 · Intake rules

deterministic

Cheap, instant, predictable. Flags an RFP before any agent reads it: a certification we do not hold, a sanctioned country, a repeat customer. A flag is advice to the agent, not a decision.

4 · Tools

deterministic

Three sub-agents the orchestrator can delegate to, then the deterministic tools they use. Untick a sub-agent and the orchestrator gets its tools directly; untick a tool and whoever needs it has to work around it.

3 · Guardrails

codehuman

Enforced inside the tools. The agent cannot talk its way past them, and neither can an RFP that tries to. Change a value, then ask again.

submit_proposal → approval card, always
price_proposal → computed from confidential unit costs; the floor is blocked in code
price_proposal → approval card for the right person
set_decision → approval card above the line
draft_proposal → compares the terms offered with the standard terms; unlimited liability blocked in code
draft_proposal · ask_customer → text is scanned; blocked in code, error returned to the agent
ask_customer → approval card
create_task → task is reassigned and flagged

From today's process to the agentic process

The same RFP, two ways. Today a bid moves between six desks; the agentic process is organised around the decisions people must take.

Today · the business process as it runs

Agentic · organised around the decisions

a personagentdeterministic codeguardrailoutcome

Buyers are moving first: source-to-pay teams are automating spot bids and RFQs, and the industry average from requisition to approved order is already 7.4 days (UiPath, How source-to-pay teams beat SLAs with agentic automation, 2025). An RFP answered in three weeks will increasingly arrive after the buyer's agent has shortlisted. The agentic process above does not remove people from the bid: it moves them from reading everything to deciding the three things that need a person, with the figures in front of them.
